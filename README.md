# Weave: 일정 관리 웹 애플리케이션

## 1. 프로젝트 소개

사용자가 회원가입 및 로그인을 한 후 개인 일정과 그룹 일정을 관리할 수 있는 웹 애플리케이션입니다.

## 2. 실행 방법

1. 프로젝트 파일을 다운로드하거나 클론합니다.
2. 프로젝트를 실행할 수 있는 개발 환경에서 엽니다.
3. `sign_up.html` 파일을 실행합니다.
   - Firebase 기능을 사용하므로 로컬 서버 환경(예: VS Code Live Server)에서 실행하는 것을 권장합니다.
4. 회원가입 및 로그인을 진행합니다.

## 3. 회원가입 및 로그인

### ① 회원가입

최초 이용자는 `sign_up.html` 페이지에서 회원가입을 진행해야 합니다.

회원가입 시 다음 정보를 입력합니다.

- 이름
- 이메일
- 비밀번호
- 비밀번호 확인

입력한 정보를 바탕으로 회원가입을 완료합니다.

### ② 로그인

회원가입이 완료되면 로그인 화면에서 다음 정보를 입력합니다.

- 이메일
- 비밀번호

로그인이 완료되면 일정 관리 페이지로 이동합니다.

## 4. 주요 기능 사용 방법

### ① 그룹 추가

로그인 후 일정 관리 페이지에 접속하면 왼쪽 사이드바에 그룹 추가 버튼을 확인할 수 있습니다.

1. 그룹 추가 버튼을 클릭합니다.
2. 다음 정보를 입력합니다
   - 그룹 이름
   - 그룹 설명
   - 그룹 색
3. 그룹을 추가합니다.
4. 추가된 그룹은 왼쪽 사이드바에서 확인할 수 있습니다.

### ② 일정 추가

그룹을 추가한 후 오른쪽 사이드바에 있는 `+` 버튼을 이용하여 일정을 추가할 수 있습니다.

1. 오른쪽 사이드바의 `+` 버튼을 클릭합니다.
2. 다음 정보를 입력합니다.
   - 일정 제목
   - 시작 날짜
   - 종료 날짜
   - 메모
3. 일정 추가를 완료합니다.
4. 추가된 일정은 달력에서 확인할 수 있습니다.
