서비스 처리 응답 구조 참고

서비스 함수는 항상 아래와 같은 규격 데이터를 반환하도록 설계되었습니다:

// 성공 시 반환 형태
{ success: true, data: { ... } }
// 실패 시 반환 형태
{ success: false, error: { code: ..., message: ... } }

코드 수정 제안 (createGroup 버그 수정 예시)

// 수정 전 (현재)
if (name && description && color) { return fail(...) }
// 수정 후 (정상 검증)
if (!name || !description || !color) {
return fail({ code: 400, message: "..." });
}
